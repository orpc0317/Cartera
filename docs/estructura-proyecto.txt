ESTRUCTURA DEL PROYECTO — CARTERA
===================================
Gestión de lotificaciones | Next.js App Router
Fecha: Noviembre 2026


Frontend:
- React 19
- TypeScript (estricto)
- Next.js 16 (App Router)


UI:
- shadcn/ui
- Tailwind CSS 4
- Base UI (@base-ui/react)
- Lucide React
- Sonner (toasts)


Backend:
- Supabase (PostgreSQL, schema cartera)
- Supabase Auth
- Server Actions de Next.js (src/app/actions)


Testing:
- Playwright (e2e, carpeta test/)


Cómo se arma una pantalla:
- page.tsx       Server Component. Carga datos y los pasa como props.
- _client.tsx    Client Component. Tabla, modal y estado de la pantalla.
- actions/*.ts   Lectura y escritura contra Supabase, con la cuenta activa.
